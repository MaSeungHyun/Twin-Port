# Port (항만)
큰 항구 전체

구조는 대략 다음과 같으며, 기간이 짦은 관계로 `Block`에 대한 컨테이너 적재 관리만을 구현하고자 합니다.

```shell
항구
├── Terminal A
│       ├── Berth (선박 접안)
│       ├── Yard (컨테이너 보관)
│       │   ├── Block (컨테이너 구역)
│       │   ├── Block (컨테이너 구역)
│       └── Gate (트럭 출입)
├── ...
```

---

## 터미널
터미널은 하나의 운영 구역으로 각 터미널을 운영 하는 회사가 존재

```shell
부산항 (Port)
│
├── Terminal A
├── Terminal B
├── Terminal C
├── Terminal D
└── ...
```

## Yard
Yard는 컨테이너를 쌓아두는 공간

```shell
Terminal
│
├── Berth (선박 접안)
├── Yard (컨테이너 보관)
├── Gate (트럭 출입)
└── Rail
```

## 용어
* `Block`: 구역
* `Bay`: 길이
* `Row`: 폭
* `Tier`: 높이(층)
