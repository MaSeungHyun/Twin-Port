# Port Twin

항만 디지털 트윈으로 구현하여 컨테이너 적재 상황을 관제하기 위한 시스템 데모 프로젝트입니다.

## 용어
* `Block`: 구역
* `Bay`: 길이
* `Row`: 폭
* `Tier`: 높이(층)

ex. B03-045-06-04 (3번 블록, Bay45, Row6, Tier4(층))

# 구현
컨테이너는 택배박스와 같이 각각 고유번호를 가진다고 확인하였습니다. 마치 택배 시스템과 같이 고유번호를 통해 컨테이너의 이동을 확인합니다.

## 기능
* 적재 구역에 대한 컨테이너의 적재량 표시 (어느 구역에 치중되어있지 않은지)
* `컨테이너 ID` 검색을 통한 컨테이너의 위치 표시 - 수많은 컨테이너를 관리하기 위하여
